- Operações matemáticas

- Estruturas de repetição
- Listas

- Strings
- Funções
- Funções recursivas
- Manipulação de matrizes
- Busca binária
- Algoritmos de ordenação
- Números primos
- Sequência de Fibonacci
- Cifra de César
- Validação de CPF
- Geração de senhas
- Manipulação de arquivos e dados
- Gráficos com Matplotlib
- Estatística básica

## Organização

Os exercícios estão organizados de forma sequencial, começando pelos conceitos básicos e avançando gradualmente para conceitos intermediários de programação em Python.
